# Retail Sales Data Analysis & Power BI Dashboard

## 1. Project Overview
This project applies data analytics techniques to a retail sales dataset. It combines Python-based exploratory data analysis (EDA), data visualization, and an interactive Microsoft Power BI dashboard to support data-driven business decisions.

## 2. Problem Statement
Retail businesses need to understand sales performance, product category trends, customer purchasing patterns, and relationships between sales variables. This project explores the available dataset to identify useful patterns and communicate findings through charts and a dashboard.

## 3. Objectives
- Inspect and prepare the dataset for analysis.
- Calculate descriptive statistics and examine data quality.
- Explore patterns, relationships, and potential outliers.
- Present findings through visualizations and a Power BI dashboard.
- Develop evidence-based business insights and recommendations.
