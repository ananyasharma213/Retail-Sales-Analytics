# Retail Sales Data Analysis & Power BI Dashboard

## Project Overview
This project analyzes retail sales data using Python, exploratory data analysis (EDA), data visualization, and Microsoft Power BI. The aim is to understand sales patterns and present useful business insights through an interactive dashboard.

## Problem Statement
Retail businesses need to understand sales performance, customer purchasing patterns, and trends to support data-driven decisions. This project uses data analytics techniques to explore the available retail sales dataset and communicate findings visually.

## Dataset Description
- Dataset: Retail sales dataset
- Format: Uploaded dataset file
- Domain: Retail and sales analytics
- The dataset is inspected for column names, data types, missing values, duplicates, and data quality issues before analysis.

## Tools Used
- Python
- Jupyter Notebook
- Pandas and NumPy
- Matplotlib and Seaborn
- Microsoft Power BI
- Git and GitHub

## Data Cleaning and Preparation
The dataset is inspected for data types, missing values, duplicate records, and incorrect entries. Data cleaning and preparation are performed where required before analysis.

## Exploratory Data Analysis (EDA)
The Python notebook contains data inspection, descriptive statistics, exploratory analysis, and investigation of patterns, relationships, and outliers where applicable.

## Data Visualizations
Charts are used to communicate relevant sales patterns, comparisons, and relationships. Visualizations and their interpretations will be documented based on the analysis results.

## Power BI Dashboard
The Power BI dashboard presents key sales metrics, visualizations, and interactive filters to help users explore the data.

## Key Business Insights
Insights will be documented from the actual EDA results and Power BI dashboard, including relevant trends and high- or low-performing areas where supported by the data.

## Business Recommendations
Recommendations will be based on verified findings from the analysis and dashboard, with a focus on improving business decisions and sales performance.

## Project Files
- `InternNova_Week4_EDA (1).ipynb` — EDA notebook
- `InternNova_Week5_Retail_Sales.pbix` — Power BI dashboard
- `retail_sales_dataset.csv.xlsx` — Uploaded dataset file

## Conclusion
This project demonstrates an end-to-end retail data analytics workflow, from data inspection and exploratory analysis to visualization and interactive dashboard development.
